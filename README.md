# Proyecto Aplicacion Movil Calculadora QR

Especificaciones Tecnicas
- React native

Funcionalidades
- Una opción que tenga un formulario que permita convertir Tasa de Efectiva Anual en Tasas Efectiva Mensual y en Tasa Efectiva Diaria
- Otra opción con un formulario que permita utilizar la camara para escanear un QR
